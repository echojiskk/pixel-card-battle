# 像素卡牌对决 · Pixel Hearth

一款纯前端实现的像素风回合制卡牌对战小游戏。玩家扮演「勇士」，与 AI 操控的「暗影术士」展开 1v1 卡牌对决——抽牌、出牌、算能量、拼护甲，先把对手生命值清零者获胜。

整个游戏只有一个 HTML 文件，零依赖、零构建，打开即玩。

## 在线试玩

> 开启 GitHub Pages 后，试玩地址为：
> `https://<你的用户名>.github.io/pixel-card-battle/`

## 玩法说明

- **对战双方**：勇士（玩家） vs 暗影术士（AI）
- **核心循环**：每回合抽牌 → 消耗能量出牌 → 结束回合，双方轮流出招
- **卡牌一览**（共 10 张）：

| 卡牌 | 类型 | 效果 |
| --- | --- | --- |
| 攻击 | 伤害 | 对敌人造成直接伤害 |
| 防御 | 防御 | 获得护甲，减免本回合受到的伤害 |
| 回血 | 恢复 | 回复自身生命值 |
| 破甲药剂 | 减益 | 降低敌方护甲 |
| 能量汲取 | 资源 | 抽取额外能量 |
| 毒药瓶 | 持续伤害 | 使敌方中毒，持续掉血 |
| 护盾强化 | 防御 | 大幅提升护甲上限与当前护甲 |
| 闪电冲击 | 伤害 | 高能耗高伤害法术 |
| 生命献祭 | 资源 | 消耗生命换取能量 |
| 补给袋 | 恢复 | 同时回复生命与能量 |

- **快捷键**：`Esc` 关闭弹窗 / 取消出牌，`Enter` 确认出牌

## 本地运行

无需任何环境，任选其一：

1. 直接用浏览器打开 `index.html`
2. 或起一个本地服务（可选）：

```bash
# Python
python -m http.server 8000
# 然后访问 http://localhost:8000
```
